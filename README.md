# STICK ARENA 3D — Forest Combat V5

棒人間のオンライン3D対戦ゲーム。ユーザーから提供された参照動画の動き・配色・演出を分析し、画像やコードを流用せず独自に実装しています。

## V5（2026-11-23）

- WASD 移動、Space 高ジャンプ。空中二段ジャンプ不可、着地後のみ再ジャンプ可能。重力を弱く調整。
- **身体の向き＝武器の向き＝カメラの水平方向**。マウスを動かすと棒人間とカメラが一緒に回転。カメラは斜め上から追従。
- E：武器固有スキル／Q：スーパー／左クリック：通常攻撃／1〜6：武器選択／ホイール：カメラ距離。
- 斧スキル（ランダム、シャッフルして4技が一巡）：青い半透明の気泡入り筒の設置、回転する斧の投擲、少し前進してからの衝撃波、回転攻撃。
- 刀の龍、各種斬撃、斧の飛び道具は移動速度を下げ、壁との衝突判定・跳ね返り／消滅を追加。
- ステージの四辺に見える外壁と実際の衝突判定。壁抜けや貫通を抑止。
- ソードの突進は徐々に加速・減速し、移動に沿って軌跡を生成。開始時に遠くへ飛ぶ演出を廃止。
- CPUの移動と武器・カメラはプレイヤーと同じ基準。爆弾／銃CPUは無限に後退せず、追撃や横移動、障害物回避、スキル使用を混ぜる。
- 森の3D背景・暖色の足場。オンライン対戦とCPU練習を継続。

## 注意

原作の物理・効果を完全複製したものではなく、動画から確認できる特徴を再現する段階の独自試作品。特に本格ラグドール、細かい攻撃当たり判定、CPUの判断能力は今後も改善が必要です。

## 実行

Node.js 20以上を使用。`npm install` → `npm start`。ローカルでは http://localhost:3000 を開く。
オンライン公開先： https://stickman-arena-3d.onrender.com

## テスト

`npm test`（移動、ジャンプ、攻撃、武器スキル、壁や投射物、ボットの基本動作）。
