# STICK ARENA 3D — V7.1 クールタイム表示と壁通過

ブラウザで遊ぶ3D棒人間対戦。制作者: 鈾。
公開先: https://stickman-arena-3d.onrender.com/

## 武器同士の接触と反動の改善 (V8)

- 武器の刃・ヘッドが接触すると、接触位置・相対速度・武器ごとの質量と慣性から両方の武器に反対向きの力積が加わる。武器だけの接触はHPを減らさない。
- 同時刻の細分化した物理ステップで双方の刃を追跡し、高速の武器同士の接触を検出。接触点で振りを抑え、次の物理ステップで反動を計算する。
- 手元は固定ではなく、衝撃を吸収して戻るばね・減衰を持つ。身体への打撃でも攻撃側・被弾側の武器が反動を受ける。投げた斧は同一の物体の速度が変化する。
- 物理パラメーターはこの3D版向けの調整値で、原作の内部定数ではない。龍・斬撃の壁通過とクールタイムは維持。

## V7.1 の追加修正

- **クールタイム表示**: 動画と同様、Skill / Super の丸いボタンが右端から反時計回りに明るく戻ります。秒数と READY 表示を取り除き、使用可能時は Skill に黄色、Super に水色の外周リングを表示。三日月・光球のアイコンと白いラベルを表示します。
- **表示と再使用の同期**: 残り時間と最大時間をサーバーから受け取り、扇形をフレーム間で補間。クールタイムそのものの長さは維持しています。使用可能リングはサーバーが再使用可能と報告したときだけ点灯します。
- **龍と飛ぶ斬撃**: 内側の障害物・足場と外壁を通過し、壁では消失・反射しません。通過後の対人判定、龍の貫通、斬撃の対人命中時の終了、寿命は従来通りです。
- **物体の衝突**: 爆弾の壁・足場での跳ね返り、ブラスター弾の壁での停止は維持しています。身体・持つ武器・飛ばした斧・筒・衝撃波の判定も変更していません。

表示の照合箇所: ソード動画 2.5秒（Super使用可能）、3.0〜5.0秒（扇形の回復）、5.5〜6.0秒（Skill使用可能）、6.5秒（使用直後）。アイコンはコードで描いたものです。

## V7 の修正

動画に見える動きとユーザーの指定を参考に、武器とダメージの仕組みを変更しました。原作の内部の物理定数を抽出したものではありません。

- **武器**: 手元の位置、姿勢、角速度をサーバーで計算。照準に柔らかく追従し、方向転換・加速・接触で揺れと行き過ぎが残ります。保持中の描画と攻撃判定は同じ姿勢を使います。
- **通常打撃**: 近接武器は移動・方向転換・スキルで物理的に動きます。通常攻撃ボタンも近接時の自動攻撃もなく、動いた刃・ヘッドと相手の身体の接触で判定します。高速の横切りも細分化して検出し、同じ接触の連打を抑えます。
- **斧の投擲**: 持つ斧そのものが離れ、手は空になります。一定距離から有限の力で帰還を試みます。速度が残るため行き過ぎ・空振りが起こり、手に近づいて相対速度が下がったときに回収します。時間切れによる瞬間帰還はありません。
- **斧の筒**: 最大24単位、半径1.45の青い流れ。設置時の視線方向に固定され、壁・足場で止まります。本人を含めて内部の身体と飛んでいる斧を連続的に押します。上向きなら上昇もします。太い輪・レール・別の爆発を取り除き、半透明の青と流れる白い泡を表示します。
- **斧の衝撃波**: 本人が短く前進し、その後、同じ斧のヘッドを中心に球殻が約0.23秒で膨張します。別の小弾や地面の円ではありません。判定も殻の到達時に行います。
- **斧のスキル**: 動画で確認した筒・投擲・衝撃波の3種をランダムな順で一巡。根拠のなかった斧の周囲スピンを削除しました。
- **ソード・刀・ハンマー**: ソード突進を約0.9秒の継続移動へ。龍は前進する頭と伸びる尾、飛ぶ斬撃は先細りの三日月へ。ハンマー回転も実際のヘッド接触で当たります。
- **ヒット表示**: 接触位置の短い白い粒、相手の白点滅、武器の減速と身体の反動。通常の空振りに大きな三日月を追加しません。
- **維持した操作**: 武器の狙い・身体・カメラの基準方向を共通化。高ジャンプは着地まで再使用できません。外壁、遮蔽物、CPUの近接・回り込みも維持しています。

映像照合に使った主な場面: 斧の筒31.4〜33.8秒、離脱・弧・回収53.2〜55.6秒、前進から球殻50.23〜50.93秒。ソード突進6.6〜7.6秒、龍0.95〜2.0秒、ハンマーの追従16.0〜16.9秒。原作素材そのものは同梱していません。

## 遊び方

部屋を作成し、CPUを追加するか、招待URLを友達に共有して開始します。

- WASD / 矢印: 視点を基準に移動
- マウス: 身体・狙い・カメラの方向。画面クリックでマウスを固定、Escで解除
- Space: ジャンプ（再使用には着地と押し直しが必要）
- 通常攻撃ボタンなし。移動・方向転換で武器が動き、接触すると打撃になります。クリックはマウス固定のみ。
- E: 武器スキル、Q: スーパー技
- 武器は対戦前に選択。R: 狙いの上下角を水平へ、ホイール: ズーム
- タッチ: 左スティックで移動・方向転換（強く上へ倒すとジャンプ）、右側は Skill と Super のみ。
- 画面：暗い足場と橙の縁、紫色の背景、人物の頭上の体力。対戦中の武器変更バー・大型HUD・照準線なし。
- 銃・爆弾の通常射撃は移動中の自動発射として暫定実装。原作と一致するかは未確認。

## 開発・検証

Node.js 20以上。

```sh
npm ci
npm test
npm start
```

http://localhost:3000 を開きます。PORT環境変数に対応。/healthは稼働確認用です。

`tests/engine.test.js` は部屋、戦闘、移動などの回帰、`tests/physics.test.js` は接触・慣性・筒・球殻・状態解除のシミュレーションを検証します。描画は `public/game.js` と `public/combat-visuals.js` がサーバーの位置と姿勢を受け取ります。クライアント独自のダメージ判定はありません。`tests/ability-hud.test.js` は実際のサーバー状態に対するクールタイム表示と、通信が遅れた場合の使用可能表示を検証します。
