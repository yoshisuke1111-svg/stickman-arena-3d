# STICK ARENA 3D

棒人間が3Dアリーナを走り回る、**オリジナルのブラウザ向けオンライン対戦ゲーム試作版**です。既存のStickman Battleのソースコードや画像は利用していません。

## 試作版の機能

- URL＋5文字の部屋コードで、離れた場所の友達と同じ部屋に入る
- 最大8人（CPUを含む）の対戦、部屋主による開始・再戦
- 3Dの第三者視点、WASD移動、ジャンプ、マウスによる視点変更
- 6種類の武器：ブレード（素早い斬撃）／ハンマー（吹き飛ばし）／ブラスター（遠距離弾）／刀（高速連撃）／爆弾（時間差・範囲爆発）／斧（高威力の重撃）
- ダッシュ攻撃と衝撃波、ノックバック、落下KO、HP・スコア・180秒対戦
- スマートフォン用の仮想スティックとタッチボタン
- CPUを部屋に追加して1人でも動作確認可能
- サーバー側で当たり判定とHPを計算（簡易アンチチート）

**試作版の制限：** 物理演算は簡易的なジャンプ・吹き飛び・落下処理です。全身のラグドール、精密なネットワーク補間、観戦、フレンド管理、戦績保存、マッチメイキングは未実装です。再接続するとプレイヤーが新しく入室するため、戦績の継続も未対応です。

## Windowsで起動する方法

1. [Node.jsのLTS版](https://nodejs.org/) をインストールする（Node 20以上）
2. ZIPを展開し、`stick-arena-3d` フォルダを開く
3. そのフォルダでターミナル（PowerShell/コマンドプロンプト）を開く
4. 次のコマンドを実行：

```bash
npm install
npm start
```

5. ブラウザで `http://localhost:3000` を開く。

同じPCの別タブでも2人プレイの確認ができます。ただし、**localhostのURLを友達に送ってもオンライン接続はできません**。友達と離れた場所で遊ぶには下記の公開が必要です。

## Renderに公開する方法

1. 新しくGitHubリポジトリを作る（既存の人狼ゲームとは別のリポジトリが無難）。
2. ZIP内の `stick-arena-3d` フォルダの中身をリポジトリのルートにアップロードする（`package.json` が最上位になるように）。
3. [Render](https://render.com/) の **New → Web Service** でリポジトリを接続する。
4. Environment を `Node`、Build Command を `npm install`、Start Command を `npm start` にする。`render.yaml` によるBlueprint作成も可能。
5. デプロイが成功したら表示された `https://...onrender.com` のURLを開く。
6. 「新しい部屋を作る」→「招待URLをコピー」から友達へ送る。**ホストもゲストも同じRenderのURLにアクセス**すること。

無料プランなどではアイドル時のスリープや起動待ちが発生する場合があります。ゲームが終了したり再デプロイされると、メモリ上の部屋は消去されます。

`/health` にアクセスすると `{"ok":true,"rooms":...}` が返ります。

## 操作方法

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | W A S D | 左下の仮想スティック |
| 視点 | 左クリックでマウス捕捉、マウスを動かす（Esc解除）/右ドラッグ | 画面右側の空白をスワイプ |
| ジャンプ | Space | JUMP |
| 攻撃 | 左クリック（長押しで連続攻撃） | ATTACK |
| ダッシュ攻撃 | E | DASH |
| スーパー衝撃波 | Q | SUPER |
| 武器切替 | 1〜6キー、または画面下の武器バー | 試合前・戦闘中の武器選択 |

中央の赤い円が光った時に乗っているとダメージを受けます。足場の外に落ちるとKOです。倒されたら数秒で復活します。180秒間で最多KOを取ろう。

**爆弾の仕様：** マウスの左クリックで前方へ投げ、約1.45秒後に範囲爆発。投擲後、地面に当たると跳ね返ります。爆発は周囲の敵に距離に応じてダメージ・ノックバックを与えます。自分には当たりません。

## 構成

```text
stick-arena-3d/
├─ package.json          Node依存（ws / three）
├─ server.js             HTTP + WebSocketサーバー、物理・対戦判定
├─ render.yaml           Render用の設定例
├─ Dockerfile            Dockerデプロイ用
├─ public/
│  ├─ index.html         UI
│  ├─ style.css          PC・スマホ表示
│  └─ game.js            Three.js 3D画面と操作
└─ tests/engine.test.js  対戦ロジックのスモークテスト
```

`npm test` でサーバーのルーム・当たり判定・復活・タイマーを検査できます。

## 注意

- WebSocketが使えるNodeサーバーへの公開が必要です。**GitHub Pagesだけではオンライン対戦できません。**
- プロトタイプです。公開した場合はスパム制限、認証、荒らし対策、負荷試験を追加してください。
- Google Fontsはネットワークから取得します。Three.jsライブラリは `npm install` で取得され、サーバーから同一ドメインで配信されます。
